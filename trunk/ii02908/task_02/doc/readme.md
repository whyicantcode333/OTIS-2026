# 1. Цель работы

Для программы, написанной в ходе выполнения лабораторной работы №1, написать тесты, используя
фреймворк "Google Test", а также провести анализ покрытия программы тестами.

# 2. Питчинг

Данная работа является расширением проекта из первой лабораторной работы. Она содержит
модульные тесты, позволяющие удостовериться в корректности изначального кода. С помощью этих
тестов возможно будет отследить ошибки, что могут возникнуть в ходе дальнейших расширений.
Важно отметить, что выбранный фреймворк, Google Test, - популярное средство от авторитетного разработчика.
То есть, вы можете быть уверены в том, что полученный продукт ещё долго будет сохранять актуальность,
получая обновления. Резюмируя, вы получаете не просто тесты, а гарантию работоспособности и полезный инструмент,
что сэкономит вам много времени и усилий, которыми можно распорядиться более эффективно.

# 3. Изменения первоначальной программы

Согласно моему варианту, моя программа работает со следующими моделями:

- **линейная модель 1.3:**  $`y_{\tau+1} = a_1*y_{\tau} + a_2*y_{\tau-1} + b*u_{\tau}`$
- **нелинейная модель 2.10:**  $`y_{\tau+1} = a*tanh(y_{\tau}) + b*u_{\tau}^3`$
- **дифференциальная модель 3.2:**  $`dy/dt = b*u`$

В первоначальной версии уже был представлен модуль анализа устойчивости.

Для более комфортной работы при организации и запуске тестов изначальный
код был разделён на несколько файлов: main.cpp, models.cpp и заголовочный файл models.h.

# 4. Тестирование

Тестирование проводится для отслеживания корректности работы отдельных частей программы. Мною были
протестированы следующие модули:

+ Методы step() для каждой модели: правильность вычисляемого значения
+ Модуль анализа устойчивости isStable(): правильность определения корней
+ Функция runSimulation(): точность количества вызовов методов модели; корректность
работы с выходными файлами (формат записи, количество строк и столбцов)
+ Функция generateSignal(): соответствие возвращаемого значения текущему tau

Для удобства работы тесты были написаны в трёх .cpp файлах.
